BEYOND SURFACE TUNING

不是套壳脚本，
而是重新设计执行链路。

市面大多免 Root 性能工具，只是简单封装脚本、表层修改参数，依赖系统开放的浅层接口。 在高负载场景下，容易出现调度迟钝、策略失效、资源冲突与掉帧发热等问题。

伽鱼这套方案基于安卓系统权限模型重新设计执行链路，深度融合系统游戏助手的性能调试接口。 核心调度逻辑采用 Rust 语言重写，不依赖 Root 权限、不注入危险钩子，在免 Root 边界内持续挖掘系统可用能力。

01
SYSTEM PATH

权限边界内重构

基于安卓权限模型重新组织调度链路，在免 Root 前提下调用系统可用的性能接口。

02
RUST CORE

核心逻辑重写

Rust 重写核心调度逻辑，不依赖 Root、不注入危险钩子，强调执行链路的稳定性。

03
ADAPTIVE ENGINE

动态负载调度

识别游戏渲染负载，动态调整 CPU / GPU 任务分发、线程亲和与温控阈值策略。
